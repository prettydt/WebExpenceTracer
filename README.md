# WebExpenceTracer

一个采用 iOS 风格设计的现代化网页记账应用。

## ✨ 特性

- 🎨 **iOS 风格设计** - 采用苹果官方设计语言，包括毛玻璃效果、系统字体和配色方案
- 💰 **收支管理** - 轻松记录收入和支出，自动计算余额
- 📊 **可视化图表** - 按类别显示支出分布的饼图
- 🎯 **预算管理** - 为各类别设置预算，实时跟踪使用情况
- 📱 **响应式设计** - 完美适配桌面和移动设备
- 💾 **本地存储** - 数据保存在浏览器本地，无需服务器

## 🎨 设计亮点

- **iOS 系统字体** - 使用 -apple-system 和 SF Pro 字体族
- **官方配色** - SF Blue (#007aff)、SF Green (#34c759)、SF Red (#ff3b30)
- **毛玻璃效果** - 导航栏使用 backdrop-filter 实现模糊效果
- **精致动画** - 点击缩放、悬停效果等流畅交互
- **无障碍设计** - 符合 WCAG 标准的字体大小和对比度

## 🚀 使用方法

1. 打开 `index.html` 文件（可以直接在浏览器中打开）
2. 在"添加记录"表单中输入描述、金额和类别
   - 正数表示收入
   - 负数表示支出
3. 点击"添加记录"按钮保存
4. 查看顶部卡片显示的余额、总收入和总支出
5. 在"图表统计"中查看支出分布
6. 在"分类预算"中设置和跟踪各类别的预算
